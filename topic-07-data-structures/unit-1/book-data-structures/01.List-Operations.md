# Step 01: List Operations

## Objective

Implement a stack and a queue using Python lists.

## Stack (LIFO - Last In, First Out)

A stack works like a pile of plates: the last item added is the first one removed.

```python
class Stack:
    def __init__(self):
        self._items = []

    def push(self, item):
        """Add an item to the top of the stack."""
        self._items.append(item)

    def pop(self):
        """Remove and return the top item."""
        if self.is_empty():
            raise IndexError("Stack is empty")
        return self._items.pop()

    def peek(self):
        """Return the top item without removing it."""
        if self.is_empty():
            raise IndexError("Stack is empty")
        return self._items[-1]

    def is_empty(self):
        return len(self._items) == 0

    def size(self):
        return len(self._items)

    def __repr__(self):
        return f"Stack({self._items})"
```

## Queue (FIFO - First In, First Out)

A queue works like a line at a shop: the first item added is the first one removed.

```python
class Queue:
    def __init__(self):
        self._items = []

    def enqueue(self, item):
        """Add an item to the back of the queue."""
        self._items.append(item)

    def dequeue(self):
        """Remove and return the front item."""
        if self.is_empty():
            raise IndexError("Queue is empty")
        return self._items.pop(0)

    def peek(self):
        """Return the front item without removing it."""
        if self.is_empty():
            raise IndexError("Queue is empty")
        return self._items[0]

    def is_empty(self):
        return len(self._items) == 0

    def size(self):
        return len(self._items)
```

## Test Both

```python
# Stack test
s = Stack()
for item in ["A", "B", "C"]:
    s.push(item)
print(f"Stack: {s}")
print(f"Pop: {s.pop()}")   # C (last in, first out)

# Queue test
q = Queue()
for item in ["A", "B", "C"]:
    q.enqueue(item)
print(f"Dequeue: {q.dequeue()}")  # A (first in, first out)
```
