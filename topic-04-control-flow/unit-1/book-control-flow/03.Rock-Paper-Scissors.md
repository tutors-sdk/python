# Step 03: Rock Paper Scissors

## Objective

Build a simple Rock Paper Scissors game using conditional logic.

## Requirements

Write a function `play_rps(player, computer)` that:

1. Accepts two strings: `"rock"`, `"paper"`, or `"scissors"`
2. Returns one of: `"Player wins!"`, `"Computer wins!"`, or `"It's a tie!"`
3. Handles invalid inputs by returning `"Invalid choice"`

## Implementation

```python
import random

def play_rps(player, computer):
    valid = {"rock", "paper", "scissors"}
    if player not in valid or computer not in valid:
        return "Invalid choice"

    if player == computer:
        return "It's a tie!"

    wins = {
        ("rock", "scissors"),
        ("paper", "rock"),
        ("scissors", "paper"),
    }

    if (player, computer) in wins:
        return "Player wins!"
    return "Computer wins!"


def play_game():
    choices = ["rock", "paper", "scissors"]
    player = input("Choose rock, paper, or scissors: ").lower()
    computer = random.choice(choices)
    print(f"Computer chose: {computer}")
    print(play_rps(player, computer))
```

## Test Cases

```python
print(play_rps("rock", "scissors"))    # Player wins!
print(play_rps("paper", "paper"))      # It's a tie!
print(play_rps("scissors", "rock"))    # Computer wins!
print(play_rps("rock", "lizard"))      # Invalid choice
```
