# Step 04: Command Dispatcher

## Objective

Build a text command processor using `match/case` (Python 3.10+).

## Requirements

Create a function `process_command(command_str)` that:

1. Parses a command string in the format `"command arg1 arg2 ..."`
2. Uses `match/case` to dispatch to the appropriate handler
3. Supports these commands:
   - `"hello [name]"` -> `"Hello, [name]!"`
   - `"add [x] [y]"` -> `"Result: [x+y]"`
   - `"repeat [n] [word]"` -> repeats word n times
   - `"quit"` or `"exit"` -> `"Goodbye!"`
   - anything else -> `"Unknown command"`

## Implementation

```python
def process_command(command_str):
    parts = command_str.strip().split()

    match parts:
        case ["hello", name]:
            return f"Hello, {name}!"
        case ["hello"]:
            return "Hello, World!"
        case ["add", x, y]:
            try:
                return f"Result: {int(x) + int(y)}"
            except ValueError:
                return "Error: add requires two numbers"
        case ["repeat", n, word]:
            try:
                return (word + " ") * int(n)
            except ValueError:
                return "Error: repeat requires a number"
        case ["quit"] | ["exit"]:
            return "Goodbye!"
        case []:
            return "No command entered"
        case _:
            return f"Unknown command: {parts[0]}"
```

## Test It

```python
commands = [
    "hello Alice",
    "hello",
    "add 10 20",
    "repeat 3 Python",
    "quit",
    "fly away",
    "",
]

for cmd in commands:
    print(f"  '{cmd}' -> {process_command(cmd)}")
```
