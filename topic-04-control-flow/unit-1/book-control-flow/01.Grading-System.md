# Step 01: Grading System

## Objective

Create a function that converts a numeric score (0-100) into a letter grade with a pass/fail indicator.

## Requirements

Write a function `grade_student(score)` that:

1. Validates that `score` is between 0 and 100 (return `"Invalid score"` otherwise)
2. Returns a tuple of `(letter_grade, status)` where:
   - **A**: 90-100 (Pass)
   - **B**: 80-89 (Pass)
   - **C**: 70-79 (Pass)
   - **D**: 60-69 (Fail)
   - **F**: 0-59 (Fail)

## Example

```python
def grade_student(score):
    if not (0 <= score <= 100):
        return "Invalid score"

    if score >= 90:
        grade = "A"
    elif score >= 80:
        grade = "B"
    elif score >= 70:
        grade = "C"
    elif score >= 60:
        grade = "D"
    else:
        grade = "F"

    status = "Pass" if grade in ("A", "B", "C") else "Fail"
    return (grade, status)

# Test it
print(grade_student(85))   # ('B', 'Pass')
print(grade_student(42))   # ('F', 'Fail')
print(grade_student(105))  # Invalid score
```

## Challenge

Extend the function to support +/- modifiers:
- Scores ending in 7-9 get a "+" (e.g., 87 -> "B+")
- Scores ending in 0-2 get a "-" (e.g., 80 -> "B-")
- Exception: there is no "A+" (97+ stays "A") and no "F+/F-"
