# Step 02: Leap Year Checker

## Objective

Implement the leap year algorithm using conditional logic.

## Rules

A year is a leap year if:
1. It is divisible by 4, **AND**
2. It is **not** divisible by 100, **UNLESS**
3. It is also divisible by 400

## Implementation

```python
def is_leap_year(year):
    if year % 400 == 0:
        return True
    if year % 100 == 0:
        return False
    if year % 4 == 0:
        return True
    return False
```

## Test Cases

```python
    result = is_leap_year(year)
    status = "PASS" if result == expected else "FAIL"
    print(f"{status}: {year} -> {result}")
```
