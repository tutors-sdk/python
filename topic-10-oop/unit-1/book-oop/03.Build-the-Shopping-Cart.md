# Step 03: Build the Shopping Cart

Create a `ShoppingCart` class that manages a collection of products.

## Requirements

### Attributes
- `items` (list): A list of tuples `(product, quantity)`
- `discount` (float): A discount percentage (0.0 to 1.0), default 0.0

### Methods
- `add_item(self, product, quantity=1)`: Add a product to the cart. If the product is already in the cart, increase the quantity
- `remove_item(self, product_name)`: Remove a product by name. Print an error if not found
- `get_subtotal(self)`: Calculate the total price before discount
- `get_total(self)`: Calculate the total price after discount. For `PhysicalProduct` items, include shipping costs
- `apply_discount(self, percentage)`: Set a discount (e.g., 0.10 for 10% off)
- `display(self)`: Print a formatted cart summary showing each item, quantities, and totals

## Example Usage

```python
cart = ShoppingCart()
cart.add_item(ebook, 2)
cart.add_item(keyboard, 1)
cart.display()
cart.apply_discount(0.10)
cart.display()
```

## Tips

- Check if a product is already in the cart before adding a duplicate
- Handle the case where `remove_item` is called with a name that is not in the cart
- For `PhysicalProduct`, add `shipping_cost * quantity` to the total
- Use `isinstance()` to check if a product is a `PhysicalProduct`
