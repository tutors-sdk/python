# Step 05: Put It All Together

Time to bring everything together in a mini shopping session that demonstrates all the features you have built.

## Task

Write a script that simulates a complete shopping experience:

### 1. Create Products
```python
# Create at least 3 products of different types
laptop = PhysicalProduct("Gaming Laptop", 1299.99, 5, 2.5, 15.00)
course = DigitalProduct("Python Course", 49.99, 500, "https://example.com/course", 250.0)
mouse = PhysicalProduct("Wireless Mouse", 29.99, 50, 0.1, 4.99)
ebook = DigitalProduct("Data Science Handbook", 19.99, 1000, "https://example.com/ds", 8.5)
```

### 2. Build a Shopping Cart
- Add products with various quantities
- Display the cart

### 3. Apply a Discount
- Apply a 15% discount
- Display the updated cart with the discount applied

### 4. Generate a Receipt
Create a `print_receipt(cart)` function that displays a nicely formatted receipt:

```
================================
        RECEIPT
================================

------------------------------------
Python Course          2   $99.98
Gaming Laptop          1   $1,299.99
  Shipping                 $15.00

  Shipping                 $14.97
------------------------------------

```

### 5. Test Validation
- Try setting a negative price (should raise ValueError)
- Try buying more than in stock (should raise ValueError or return appropriate message)

## Tips

- Use string formatting for alignment: `f"{'Item':<20}"` for left-aligned, `f"{'Price':>10}"` for right-aligned
- This is your chance to show all the OOP concepts working together
- Think about edge cases: empty cart, zero quantity, etc.
