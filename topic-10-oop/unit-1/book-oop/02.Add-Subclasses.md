# Step 02: Add Subclasses

Now extend the `Product` class with two specialized product types.

## DigitalProduct

A product that can be downloaded. Inherits from `Product`.

### Additional Attributes
- `download_link` (str): URL to download the product
- `file_size` (float): Size in MB

### Additional Methods
- `__str__(self)`: Override to include "[Digital]" prefix, e.g., `"[Digital] Python eBook - $29.99 (100 in stock, 15.5 MB)"`

## PhysicalProduct

A product that needs to be shipped. Inherits from `Product`.

### Additional Attributes
- `weight` (float): Weight in kg
- `shipping_cost` (float): Cost to ship one unit

### Additional Methods
- `__str__(self)`: Override to include "[Physical]" prefix, e.g., `"[Physical] Keyboard - $79.99 (20 in stock, 0.8 kg)"`
- `total_cost(self)`: Return `price + shipping_cost` (total cost for one unit including shipping)

## Example Usage

```python
ebook = DigitalProduct("Python eBook", 29.99, 100, "https://example.com/book", 15.5)
keyboard = PhysicalProduct("Keyboard", 79.99, 20, 0.8, 9.99)

print(ebook)
print(keyboard)
print(f"Keyboard total with shipping: ${keyboard.total_cost():.2f}")
```

## Tips

- Use `super().__init__()` to call the parent constructor
- Remember to pass `name`, `price`, and `quantity` to the parent
