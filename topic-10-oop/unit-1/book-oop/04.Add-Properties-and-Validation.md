# Step 04: Add Properties and Validation

Enhance the `Product` class with properties and validation to make it more robust.

## Requirements

### Price Property
Add a `@property` for `price` that:
- Returns the current price
- Has a setter that validates: price must be a positive number
- Raises `ValueError` with a descriptive message if invalid

### Quantity / Stock Checking
Add a method `is_in_stock(self, requested=1)` that:
- Returns `True` if `quantity >= requested`
- Returns `False` otherwise

Add a method `reduce_stock(self, amount)` that:
- Decreases `quantity` by `amount`
- Raises `ValueError` if `amount > quantity`

### Formatted Display
Add a property `formatted_price` that returns the price as a currency string like `"$29.99"`.

## Example Usage

```python
p = Product("Widget", 9.99, 10)
print(p.formatted_price)       # $9.99
print(p.is_in_stock(5))        # True
print(p.is_in_stock(15))       # False

p.reduce_stock(3)
print(p.quantity)               # 7

p.price = -5  # raises ValueError
```

## Tips

- Use `_price` as the internal attribute name
- Update `__init__` to use the setter (assign to `self.price`, not `self._price`)
- The setter will automatically validate on construction too
