# Step 01: Define the Base Class

In this step, you will create the foundation of the shopping system -- a `Product` class.

## Requirements

Create a `Product` class with the following:

### Attributes
- `name` (str): The product name
- `price` (float): The price in dollars
- `quantity` (int): Number in stock

### Methods
- `__init__(self, name, price, quantity)`: Initialize all attributes
- `__str__(self)`: Return a user-friendly string like `"Laptop - $999.99 (5 in stock)"`
- `__repr__(self)`: Return a developer-friendly string like `"Product('Laptop', 999.99, 5)"`
- `total_value(self)`: Return `price * quantity`

## Example Usage

```python
p = Product("Laptop", 999.99, 5)
print(p)              # Laptop - $999.99 (5 in stock)
print(repr(p))        # Product('Laptop', 999.99, 5)
print(p.total_value()) # 4999.95
```

## Tips

- Use f-strings for formatting
- Format prices to 2 decimal places with `:.2f`
- This class will be the parent for specialized product types in the next step
