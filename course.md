# Python Fundamentals

Welcome to Python Fundamentals! This course takes you from zero to confident Python programmer through interactive Jupyter notebooks, visual diagrams, slide presentations, and hands-on labs.

## What You'll Learn

- **Variables & Types** — integers, floats, strings, booleans
- **Control Flow** — if/elif/else, match/case
- **Loops** — for, while, comprehensions
- **Functions** — parameters, scope, lambdas
- **Data Structures** — lists, tuples, dicts, sets
- **File I/O & Errors** — reading, writing, exception handling
- **Modules** — standard library, pip, virtual environments
- **OOP** — classes, inheritance, properties, dataclasses

## How This Course Works

Each topic includes:
- **Slides** introducing key concepts
- **Notebooks** with interactive examples and exercises
- **Diagrams** visualizing relationships and decision flows
- **Labs** with guided, hands-on challenges

Open the notebooks in your own Jupyter environment to follow along and complete the exercises!
