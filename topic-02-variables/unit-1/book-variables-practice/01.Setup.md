# Step 01: Setup

In this step, you will create variables of each core Python type and verify them.

## Instructions

1. Create a new Python file called `variables_lab.py`
2. Declare the following variables:

```python
# Integers
student_count = 30
year = 2024

# Floats
average_grade = 85.5
pi = 3.14159

# Strings
course_name = "Python Fundamentals"
instructor = "Dr. Smith"

# Booleans
is_active = True
has_prerequisite = False

# None
final_grade = None
```

3. Print each variable along with its type:

```python
print(f"student_count = {student_count} ({type(student_count).__name__})")
print(f"average_grade = {average_grade} ({type(average_grade).__name__})")
print(f"course_name = {course_name} ({type(course_name).__name__})")
print(f"is_active = {is_active} ({type(is_active).__name__})")
print(f"final_grade = {final_grade} ({type(final_grade).__name__})")
```

4. Run your file and verify the output shows the correct type for each variable.

## Expected Output

```
student_count = 30 (int)
average_grade = 85.5 (float)
course_name = Python Fundamentals (str)
is_active = True (bool)
final_grade = None (NoneType)
```
