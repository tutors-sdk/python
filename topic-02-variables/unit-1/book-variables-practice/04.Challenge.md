# Step 04: Challenge - Mad Libs

Build a Mad Libs program that uses multiple variable types and string formatting.

## What is Mad Libs?

Mad Libs is a word game where you fill in blanks with specific types of words (noun, verb, adjective, etc.) to create a funny story.

## Instructions

1. Create variables for Mad Libs inputs (simulate user input):

```python
# Mad Libs inputs (in a real program, these would come from input())
adjective_1 = "fluffy"
noun_1 = "dragon"
verb_past = "danced"
number = 42
adjective_2 = "sparkly"
noun_2 = "pizza"
verb_present = "juggling"
place = "the moon"
float_value = 3.14
is_funny = True
```

2. Build the story using f-strings:

```python
story = f"""
{'=' * 50}
{'MAD LIBS: The Python Adventure':^50}
{'=' * 50}

Once upon a time, a {adjective_1} {noun_1} was walking
through {place}. It had been {verb_present} for exactly
{number} hours and {float_value:.1f} minutes.

Suddenly, it found a {adjective_2} {noun_2} lying on the
ground! The {noun_1} {verb_past} with joy.

"This is {'hilarious' if is_funny else 'not funny'}!"
said the {noun_1}, picking up the {noun_2}.

THE END
{'=' * 50}
"""

print(story)
```

3. Add a "story stats" section at the bottom:

```python
# Story stats
total_words = len(story.split())
total_chars = len(story)
unique_words = len(set(story.lower().split()))

print(f"{'Story Statistics':^50}")
print(f"-" * 50)
print(f"Total words:  {total_words:>10,}")
print(f"Total chars:  {total_chars:>10,}")
print(f"Unique words: {unique_words:>10,}")
print(f"Funny:        {'Yes':>10}" if is_funny else f"Funny:        {'No':>10}")
```
