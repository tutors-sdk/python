# Step 03: String Formatting

Build a formatted receipt using f-strings with alignment and number formatting.

## Instructions

Create a program that prints a nicely formatted receipt:

```python
# Receipt data
items = [
    ("Widget A", 3, 9.99),
    ("Gadget B", 1, 24.50),
    ("Doohickey", 5, 2.75),
    ("Thingamajig", 2, 15.00),
]
tax_rate = 0.08

# Print the receipt header
print("=" * 45)
print(f"{'PYTHON STORE RECEIPT':^45}")
print("=" * 45)
print(f"{'Item':<15} {'Qty':>5} {'Price':>8} {'Total':>10}")
print("-" * 45)

# Print each item
subtotal = 0
for name, qty, price in items:
    total = qty * price
    subtotal += total
    print(f"{name:<15} {qty:>5} {price:>8.2f} {total:>10.2f}")

# Print totals
tax = subtotal * tax_rate
grand_total = subtotal + tax

print("-" * 45)
print(f"{'Subtotal:':>30} {subtotal:>10.2f}")
print(f"{'Tax (8%):':>30} {tax:>10.2f}")
print(f"{'TOTAL:':>30} {grand_total:>10.2f}")
print("=" * 45)
```

## Expected Output

```
=============================================
          PYTHON STORE RECEIPT
=============================================
Item              Qty    Price      Total
---------------------------------------------
Widget A            3     9.99      29.97
Gadget B            1    24.50      24.50
Doohickey           5     2.75      13.75
Thingamajig         2    15.00      30.00
---------------------------------------------
                     Subtotal:      98.22
                      Tax (8%):       7.86
                        TOTAL:     106.08
=============================================
```
