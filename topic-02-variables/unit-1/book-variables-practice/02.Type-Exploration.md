# Step 02: Type Exploration

Now let's explore Python's type system more deeply using `isinstance()` and experimenting with invalid conversions.

## Instructions

1. Add the following code to test `isinstance()`:

```python
# isinstance() checks
print("--- isinstance() checks ---")
print(f"isinstance(42, int):       {isinstance(42, int)}")
print(f"isinstance(42, float):     {isinstance(42, float)}")
print(f"isinstance(True, bool):    {isinstance(True, bool)}")
print(f"isinstance(True, int):     {isinstance(True, int)}")  # True! bool is subclass of int
print(f"isinstance(3.14, (int, float)): {isinstance(3.14, (int, float))}")
```

2. Experiment with conversions that fail. Wrap them in try/except:

```python
# What happens with invalid conversions?
print("\n--- Invalid Conversions ---")

test_values = ["hello", "12.5", "", "42", "True"]
for val in test_values:
    try:
        result = int(val)
        print(f"int('{val}') = {result}")
    except ValueError as e:
        print(f"int('{val}') -> ValueError: {e}")
```

3. Explore the relationship between bool and int:

```python
print("\n--- bool and int relationship ---")
print(f"True + True = {True + True}")
print(f"True * 10 = {True * 10}")
print(f"False + 42 = {False + 42}")
print(f"sum([True, False, True, True]) = {sum([True, False, True, True])}")
```
