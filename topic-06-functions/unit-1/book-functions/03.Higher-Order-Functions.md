# Step 03: Higher-Order Functions

## Objective

Implement your own versions of Python's built-in `map`, `filter`, and `reduce`.

## Functions to Implement

### 1. `my_map(func, iterable)`

```python
def my_map(func, iterable):
    return [func(item) for item in iterable]

print(my_map(lambda x: x ** 2, [1, 2, 3, 4, 5]))
# [1, 4, 9, 16, 25]
```

### 2. `my_filter(func, iterable)`

```python
def my_filter(func, iterable):
    return [item for item in iterable if func(item)]

print(my_filter(lambda x: x % 2 == 0, range(10)))
# [0, 2, 4, 6, 8]
```

### 3. `my_reduce(func, iterable, initial=None)`

```python
def my_reduce(func, iterable, initial=None):
    it = iter(iterable)
    if initial is None:
        result = next(it)
    else:
        result = initial
    for item in it:
        result = func(result, item)
    return result

# Sum
print(my_reduce(lambda a, b: a + b, [1, 2, 3, 4, 5]))  # 15

# Product
print(my_reduce(lambda a, b: a * b, [1, 2, 3, 4, 5]))  # 120

# Max
print(my_reduce(lambda a, b: a if a > b else b, [3, 1, 4, 1, 5, 9]))  # 9
```

## Challenge

Combine all three to process data: given a list of strings, find the total length of strings that start with a vowel.
