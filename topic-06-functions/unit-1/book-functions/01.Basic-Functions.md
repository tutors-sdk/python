# Step 01: Basic Functions

## Objective

Write three string utility functions.

## Functions to Implement

### 1. `is_palindrome(text)`
Returns `True` if the text is a palindrome (reads the same forwards and backwards). Ignore case and spaces.

```python
def is_palindrome(text):
    cleaned = text.lower().replace(" ", "")
    return cleaned == cleaned[::-1]

print(is_palindrome("racecar"))      # True
print(is_palindrome("Race Car"))     # True
print(is_palindrome("hello"))        # False
print(is_palindrome("A man a plan a canal Panama"))  # True
```

### 2. `count_vowels(text)`
Returns the number of vowels (a, e, i, o, u) in the text. Case-insensitive.

```python
def count_vowels(text):
    return sum(1 for char in text.lower() if char in "aeiou")

print(count_vowels("Hello World"))   # 3
print(count_vowels("Python"))        # 1
```

### 3. `title_case(text)`
Converts text to title case without using the built-in `.title()` method. Capitalize the first letter of each word.

```python
def title_case(text):
    return " ".join(word[0].upper() + word[1:].lower() for word in text.split() if word)

print(title_case("hello world"))         # Hello World
print(title_case("PYTHON IS GREAT"))     # Python Is Great
```
