# Step 02: Parameter Patterns

## Objective

Create a flexible `format_table` function using `*args` and `**kwargs`.

## Requirements

Write `format_table(*rows, **options)` that:
- Accepts any number of rows (each row is a tuple or list)
- Supports these options:
  - `headers`: list of column headers (default: None)
  - `separator`: character between columns (default: `" | "`)
  - `align`: `"left"`, `"right"`, or `"center"` (default: `"left"`)

## Implementation

```python
def format_table(*rows, headers=None, separator=" | ", align="left"):
    all_rows = [headers] + list(rows) if headers else list(rows)

    # Find the widest entry in each column
    col_widths = [
        max(len(str(row[i])) for row in all_rows)
        for i in range(len(all_rows[0]))
    ]

    def format_row(row):
        cells = []
        for value, width in zip(row, col_widths):
            s = str(value)
            if align == "right":
                cells.append(s.rjust(width))
            elif align == "center":
                cells.append(s.center(width))
            else:
                cells.append(s.ljust(width))
        return separator.join(cells)

    lines = []
    if headers:
        lines.append(format_row(headers))
        lines.append(separator.join("-" * w for w in col_widths))

    for row in rows:
        lines.append(format_row(row))

    return "\n".join(lines)
```

## Test It

```python
print(format_table(
    ("Alice", 85, "A"),
    ("Bob", 92, "A+"),
    ("Charlie", 78, "B+"),
    headers=["Name", "Score", "Grade"],
    align="center"
))
```
