# Step 04: Comprehension Challenges

## Objective

Solve these problems using comprehensions (list, dict, or set).

## Challenge 1: Flatten a 2D List

```python
matrix = [[1, 2, 3], [4, 5, 6], [7, 8, 9]]

# Flatten to [1, 2, 3, 4, 5, 6, 7, 8, 9]
flat = [num for row in matrix for num in row]
print("Flattened:", flat)
```

## Challenge 2: Transpose a Matrix

```python
matrix = [[1, 2, 3], [4, 5, 6], [7, 8, 9]]

# Transpose: swap rows and columns
transposed = [[row[i] for row in matrix] for i in range(len(matrix[0]))]
print("Original:")
for row in matrix:
    print(f"  {row}")
print("Transposed:")
for row in transposed:
    print(f"  {row}")
```

## Challenge 3: Word Frequency Counter

```python
text = "the cat sat on the mat the cat liked the mat"
words = text.split()

# Count word frequencies
freq = {}
for word in words:
    freq[word] = freq.get(word, 0) + 1

# Sort by frequency (descending)
sorted_freq = dict(sorted(freq.items(), key=lambda x: x[1], reverse=True))
print("Word frequencies:", sorted_freq)

# Bonus: using comprehension to filter words appearing more than once
common = {word: count for word, count in freq.items() if count > 1}
print("Words appearing more than once:", common)
```
