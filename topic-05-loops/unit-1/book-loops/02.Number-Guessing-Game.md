# Step 02: Number Guessing Game

## Objective

Create a number guessing game using a `while` loop with hints.

## Requirements

1. Generate a random number between 1 and 100
2. Give the player up to 7 guesses
3. After each wrong guess, tell them if the target is higher or lower
4. Track the number of attempts

## Implementation

```python
import random

def guessing_game():
    target = random.randint(1, 100)
    max_attempts = 7
    attempts = 0

    print("I'm thinking of a number between 1 and 100.")
    print(f"You have {max_attempts} attempts.\n")

    while attempts < max_attempts:
        attempts += 1
        remaining = max_attempts - attempts

        try:
            guess = int(input(f"Attempt {attempts}: Enter your guess: "))
        except ValueError:
            print("Please enter a valid number!")
            attempts -= 1  # Don't count invalid input
            continue

        if guess == target:
            print(f"\nCongratulations! You got it in {attempts} attempts!")
            return True
        elif guess < target:
            print(f"Too low! ({remaining} attempts left)")
        else:
            print(f"Too high! ({remaining} attempts left)")

    print(f"\nGame over! The number was {target}.")
    return False
```

## Testing Without Input

For testing without user input, create a version that accepts a list of guesses:

```python
def guessing_game_auto(target, guesses):
    for i, guess in enumerate(guesses, 1):
        if guess == target:
            return f"Found {target} in {i} attempts!"
        elif guess < target:
            print(f"  Attempt {i}: {guess} -> Too low")
        else:
            print(f"  Attempt {i}: {guess} -> Too high")
    return f"Failed to find {target} in {len(guesses)} attempts"

print(guessing_game_auto(42, [50, 25, 37, 43, 40, 42]))
```
